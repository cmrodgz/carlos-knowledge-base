# Overview

The decisions developers make during the production process directly affects the quality of the final product. A company must balance content, performance, accessibility, gameplay, graphics, and other features while staying within the project's budget and timeline. 

## Balancing Resources and Quality

Developers always have some sort of limited resources that they have to manage. Whether it be a specific release date, a fixed budget, or a specific number of staff, a project will not have an unlimited amount of resources. This forces the development team to determine which features should be prioritized and receive the majority of the attention. 

By adding more content and quality features to the game, there will have to be an increase in  [[development-costs|Development Costs]] for the project. The teams developing the project will also need to focus on certain features if the project goes through delays, as discussed in [[development-timelines-and-delays|Development Timelines and Delays]].

## Technical Decisions

When developing a game, there are technical and design decisions that need to be made. From how games look, to how the gameplay system works, or how the game will perform on different platforms. The bigger the scope of the game is, the more important these decisions become as the player's experience is more likely to be affected. 

## Game Testing 

Testing a game is a vital part of the game development process. This allows the team to find technical problems, bugs, and performance issues before the game is released to the public. This is especially important to a games [[launch-performance|Launch Performance]] and overall chance to succeed commercially. 

## Development Decisions and Commercial Performance

These decisions which influence the overall quality of the game have direct connections to the performance of the product in the video game market. Being able to balance timelines, budgets, and technical limitations effectively gives a project the highest chance of becoming commercially successful. It is important to understand how these decisions affect how the product performs regarding, [[player-retention|Player Retention]], [[critical-reception|Critical Reception]], and [[sales-performance|Sales Performance]].
